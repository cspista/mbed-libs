# Archived Mbed 2 (Classic) Libraries for gcc4mbed

This repository is a preserved collection of community-contributed (user contribution) libraries for **Mbed 2 (Mbed Classic)**. These libraries were salvaged from `mbed.org` before its retirement to ensure long-term availability and maintainability.

They are primary dependencies for the educational materials, lab exercises, and sample projects found at:
👉 **[https://cspista.hu/mbed](https://cspista.hu/mbed)**

---

## 🛠️ Installation & Usage (gcc4mbed)

To use these libraries in your offline `gcc4mbed` development environment:

1. Clone or download this repository.
2. Copy the entire `mbed-libs` directory into your `gcc4mbed` setup under the `external` path:
   ```text
   <gcc4mbed-root>/external/mbed-libs/
